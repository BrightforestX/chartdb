# Development Rules

## Code Style
- Follow existing TypeScript/React patterns in the codebase
- Use functional components with hooks
- Maintain proper type safety
- Follow the project's ESLint and Prettier configuration

## Testing
- Write tests for new features
- Ensure all tests pass before committing
- Test integrations thoroughly

## Documentation
- Document all public APIs
- Add inline comments for complex logic
- Update README and relevant docs

## Git Workflow
- Commit frequently with clear messages
- Push changes after completing each major task
- Keep commits focused and atomic

## Integration Standards
- Follow MCP specification for server implementation
- Use Pipedream best practices for components
- Implement proper error handling and logging
- Ensure security for external integrations
