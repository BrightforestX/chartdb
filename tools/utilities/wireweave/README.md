# Wireweave UI Component Spec

Wireweave provides standardized UI components for ChartDB flows.

## Components

### FlowCard
A card component for displaying flow steps and content. Extends base Card with flow-specific styling.

### Stepper
Step indicator for multi-step flows (e.g., create diagram: Select DB → Import → Select Tables).

### DataTable
Enhanced table component for displaying structured data with sorting, selection.

### Chip
Pill/badge component for tags, status, and compact labels.

### BottomNav
Bottom navigation bar for mobile/compact layouts.
